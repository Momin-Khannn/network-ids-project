# 🛡️ Network Intrusion Detection System (IDS) using Machine Learning

An end-to-end ML project to detect network intrusions using the **NSL-KDD dataset**.

## 📌 Project Overview
Builds an ML-based IDS that classifies network connections as **normal** or **attack** (DoS, Probe, R2L, U2R).

## 📊 Dataset
- **NSL-KDD** — improved version of KDD Cup 1999
- 41 features + 1 label | 125,973 training records | 22,544 test records

## 🔬 Session 1: EDA Complete ✅

- Target variable distribution (attack types)
- Feature correlation heatmap
- Protocol & service analysis
- Missing value check → Zero missing values!
- Class imbalance identified (DoS dominates)
